# Databricks Forge Quick Start

The canonical quick start is maintained at
[docs/quickstart.md](docs/quickstart.md).

Start with:

```bash
git clone https://github.com/databricks-solutions/databricks-forge.git
cd databricks-forge
databricks auth login --host https://your-workspace.cloud.databricks.com
./deploy.sh
```

Continue with the [full quick start](docs/quickstart.md) for prerequisites,
permissions, verification, updates, cleanup, and troubleshooting.
