# Support

Databricks Forge is a community-maintained Databricks Field Engineering
accelerator. It is not an official Databricks product and is not covered by
Databricks Support or an SLA.

## Get help

1. Read the [Quick Start](docs/quickstart.md) and
   [Deployment Guide](docs/DEPLOYMENT.md).
2. Search [existing issues](https://github.com/databricks-solutions/databricks-forge/issues).
3. Ask usage questions in
   [GitHub Discussions](https://github.com/databricks-solutions/databricks-forge/discussions).
4. Open a bug report when you can provide reproducible steps.

Community responses are best effort.

## Include with a bug report

- Forge version
- Databricks cloud and workspace region
- Deployment method
- Relevant app and browser logs
- Reproduction steps and expected behavior

Remove tokens, credentials, customer data, workspace URLs, resource IDs, email
addresses, and other sensitive values before posting.

## Security issues

Do not report vulnerabilities in public issues or discussions. Use
[GitHub private vulnerability reporting](https://github.com/databricks-solutions/databricks-forge/security/advisories/new).
